# Knowledge Benchmarks

| Category | Measures |
|----------|----------|
| Retrieval | Correct source found for research question |
| Citation | Correct claim attribution |
| Synthesis | Multi-source combination accuracy |
| Conflict detection | Disagreement recognized |
| Knowledge graph | Correct entity/relation construction |
| Gap detection | Genuine unanswered questions identified |
| Temporal reasoning | Old vs new knowledge distinguished |
| Provenance | Every claim traceable to source |
| Coverage estimation | Honest saturation reporting |
| Scope isolation | Private knowledge not leaked |
