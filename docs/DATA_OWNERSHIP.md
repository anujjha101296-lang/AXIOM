# Research Data Ownership

1. **Customer Ownership**: The user retains 100% intellectual property ownership of any hypothesis, code, mathematical formulation, or formal proof generated within AXIOM's Research Workspaces.
2. **No Model Training**: AXIOM does NOT use private user research data, uploaded PDFs, or proprietary mathematical algorithms to train foundational LLMs.
3. **Data Export**: Users can export their entire Epistemic Knowledge Graph via API or UI in Markdown and JSON formats, preserving citations, verification states, and provenance links.
4. **Data Deletion**: Upon account or project deletion, all associated `MathematicalClaimNode`, `DocumentChunk`, and `VerificationAttempt` objects are hard-deleted. We do not retain orphaned data. Failed payments freeze creation access but do NOT trigger data deletion.
