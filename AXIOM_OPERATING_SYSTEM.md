# AXIOM Operating System

AXIOM is a **self-improving research organization**, not a sequence of prompts.

This repository is governed by the **Continuous Evolution Loop** — a permanent feedback cycle where evidence, benchmarks, and recorded progress determine what gets built next.

## The loop (summary)

```text
Vision → Roadmap → Campaigns → Gap Analysis → Initiative
  → Design → Implement → Test → Benchmark → Review
  → Document → Commit → Validate → Reflect → Update → Repeat
```

## Principle

> Can AXIOM now do something it couldn't do last month?

If the answer is no, the loop is not complete — regardless of how many features were added.
