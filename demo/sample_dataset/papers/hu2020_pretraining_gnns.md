# Hu et al. 2020 — Strategies for Pre-training Graph Neural Networks

## Abstract (demo excerpt)

We propose multi-level pre-training strategies for GNNs on large molecular corpora. Context prediction and graph-level supervised objectives improve downstream performance on MoleculeNet benchmarks.

## Key concepts for extraction

- GNN pre-training
- Context prediction objective
- Graph-level supervised pre-training
- Transfer learning for molecular property prediction

## Findings

1. Pre-training improves data-scarce downstream tasks
2. Graph-level objectives help classification more than regression
3. Deeper pre-trained encoders can outperform shallow from-scratch models
