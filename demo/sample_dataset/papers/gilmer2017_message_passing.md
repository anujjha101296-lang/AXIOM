# Gilmer et al. 2017 — Neural Message Passing for Quantum Chemistry

## Abstract (demo excerpt)

We reformulate graph convolutions as message passing on molecular graphs. The MPNN framework unifies several prior architectures and achieves competitive results on QM9 quantum chemistry regression tasks.

## Key concepts for extraction

- Message passing neural networks (MPNN)
- Molecular graph representation
- Edge-conditioned filtering
- Set2Set readout
- QM9 benchmark

## Findings

1. Message functions can be learned rather than hand-designed
2. Edge features improve property prediction accuracy
3. Model depth beyond 4 layers shows diminishing returns on QM9 from scratch
